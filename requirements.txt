# Kafka client used to consume S3 event notifications from the VAST
# Kafka-compatible Event Broker. Bundles librdkafka.
#
# Version window is deliberate and VAST-specific. VAST documents support for
# the Confluent Kafka Python client 2.4 - 2.8 against the VAST Kafka-compatible
# Event Broker, and states that aiokafka is not supported:
#   https://kb.vastdata.com/documentation/docs/kafka-protocol-support.md
# Newer clients may well work, but a customer demo is the wrong place to find
# out. Widen this only after testing against your cluster.
confluent-kafka>=2.4,<2.9
